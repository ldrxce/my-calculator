# JS Calculator

A simple browser-based calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Clear button to reset the calculator
- Real-time display updates
- Division-by-zero guard with an "Error" result
- Responsive, clean interface

## Project Structure

- `index.html` — calculator layout
- `styles.css` — page styling
- `script.js` — calculator logic

## How to Run

1. Open `index.html` directly in your browser, or
2. Serve the project locally:

```bash
cd my-calculator
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Notes

This project is a lightweight front-end app and does not require any build tools or package installation.
